# NovaTech Azure Infrastructure Project

## Platform Explorers Cohort 2 — AZ-104 Track

This project is based on **Use Case 2: Scaling NovaTech for Europe**.

The goal of this lab was to extend NovaTech's Azure infrastructure from the United States to Western Europe while implementing:

- Multi-region networking
- VNet Peering
- Private DNS Zones
- Load Balancing
- Azure Container Instances (ACI)
- Azure Key Vault
- Log Analytics & Monitoring
- Azure Monitor Alerts
- Azure Budgets
- Security Review and Governance

## Architecture Summary

- East US and West Europe infrastructure deployment
- Cross-region VNet peering
- Private DNS resolution
- Highly available web tier with Load Balancer
- Containerized workloads using ACI
- Centralized logging and monitoring
- Cost management and security governance
